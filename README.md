# About Label Blend

Label Blend is an AI-powered desktop application designed for computer vision engineers, AI researchers, educators, and developers.

The software enables users to create high-quality synthetic datasets by combining foreground PNG objects with custom background images while automatically generating annotation files compatible with modern machine learning workflows.

## Features

- 🖼 Synthetic image generation
- 🎨 Image augmentation
- 🏷 Automatic annotation generation
- 📦 Object Detection dataset creation
- ✂ Image Segmentation dataset creation
- 🔍 Bounding box visualization
- ⚡ High-speed local processing
- 🤖 AI-assisted labeling
- 📁 Project management
- 💾 Multiple export formats
